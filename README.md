# HR Agent Prototype (squelette)

Prototype d'un agent RH expert (FastAPI + React) — MVP :
- FAQ & recherche documentaire (embeddings)
- Chatbot conversationnel connecté à OpenAI
- Squelette RGPD (redaction/consentement, logs, conservation)

Prérequis :
- Docker & docker-compose
- Clé OpenAI

Lancer en local :
1. Copier `.env.example` -> `.env` et remplir les valeurs
2. docker-compose up --build
3. Backend: http://localhost:8000
4. Frontend: http://localhost:3000

Remarque RGPD :
- Les logs sensibles sont masqués par défaut.
- Option de conservation des conversations configurable via .env
